This repository contains the data and code used in the article “Bayesian Renshaw–Haberman and Hybrid Machine Learning Models for Mortality Forecasting in India”. It includes cleaned abridged life table inputs for India (male and female, 2000–2020) derived from the UN Human Life Tables Database and the Sample Registration System (SRS) 2016–2020, together with the Stan models, Python pseudo scripts, and workflow for reproducing all figures, tables, and life expectancy projections reported in the paper.
