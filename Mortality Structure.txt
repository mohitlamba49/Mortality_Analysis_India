       - Run MCMC sampling

   - Plot:
       • Age effects

   - Compute fitted mortality rates
   - Compute:
       • Residuals
       • Pearson residuals
   - Compare observed vs fitted

       • Deaths by year

   - Fit model on training set
   - Predict on test set
   - Compute:
       • MAE
       • RMSE
