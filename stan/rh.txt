MODEL: RH (Age + Period + Cohort + Sex)

DATA:
   Input N, A, T, C, S
   Input age[n], year[n], cohort[n], sex[n]
   Input deaths[n], exposure[n]

PARAMETERS:
   alpha[A, S]        # age-specific baseline
   beta[A, S]         # age-specific sensitivity
   kappa_raw[T]       # time index
   gamma_raw[C, S]    # cohort effects

   sigma_kappa        # variance for time RW
   sigma_gamma        # variance for cohort RW
   phi                # overdispersion

TRANSFORM:
   kappa = center(kappa_raw)
   FOR each sex:
       gamma[:, s] = center(gamma_raw[:, s])

MODEL:
   Priors:
       alpha ~ Normal(0, 3)
       beta  ~ Normal(0, 0.5)
       sigma_kappa ~ Exponential(1)
       sigma_gamma ~ Exponential(1)
       phi ~ Gamma(10, 1)

   Time random walk:
       kappa[1] ~ Normal(0,1)
       FOR t = 2 to T:
           kappa[t] ~ Normal(kappa[t-1], sigma_kappa)

   Cohort random walk:
       FOR each sex s:
           gamma[1,s] ~ Normal(0,1)
           FOR c = 2 to C:
               gamma[c,s] ~ Normal(gamma[c-1,s], sigma_gamma)

   Likelihood:
       FOR each observation n:
           eta = alpha[age[n], sex[n]]
               + beta[age[n], sex[n]] * kappa[year[n]]
               + gamma[cohort[n], sex[n]]

           deaths[n] ~ NegBinomial(log(exposure[n]) + eta, phi)

GENERATED:
   FOR each n:
       compute log_lik[n]
       simulate y_rep[n]
